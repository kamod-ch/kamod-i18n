# Internationalization you can try, not just read about

This PreactPress site is both the documentation for `@kamod-ch/i18n` and a working consumer of the package. Change the language, add users, and compare locale-aware currency and date output below.

<I18nExample />

## What the example demonstrates

- typed nested translation keys and interpolation
- locale-aware plural selection through `Intl.PluralRules`
- number and date formatting with native `Intl` APIs
- reactive Preact components using `I18nProvider`, `useI18n`, and `useLocale`
- an asynchronously loaded French locale

## The same setup in your app

```tsx
import { createI18n } from "@kamod-ch/i18n";
import { I18nProvider, useI18n } from "@kamod-ch/i18n/preact";

const en = {
  greeting: "Welcome, {name}!",
  users: { one: "{count} user", other: "{count} users" },
} as const;

const i18n = createI18n({
  locale: "en",
  fallbackLocale: "en",
  messages: {
    en,
    de: () => import("./locales/de"),
  },
});

function Greeting() {
  const { t } = useI18n<typeof en, "en" | "de">();
  return <p>{t("greeting", { name: "Ada" })}</p>;
}

export function App() {
  return (
    <I18nProvider i18n={i18n}>
      <Greeting />
    </I18nProvider>
  );
}
```
